# Primera escena visual 3D — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Entregar una muestra 3D de la granja y parar para revisión visual del usuario.
**Architecture:** Una entrada Vite independiente usa Three.js para representar un World local. El juego actual mantiene sus cuentas, controles y servidor.
**Tech Stack:** TypeScript, Three.js, Vite, Playwright. Modelos originales por geometría; sin descargas de arte.
**Spec:** ../specs/2026-10-12-visual-3d-design.md

## Global Constraints
- Prioridad visual; parar tras entregar la escena y sus capturas.
- Cámara ortográfica isométrica, luz cálida, sombras suaves, sin panel lateral.
- Dos personajes, casa, huerta, árboles, piedras, senderos y cercas.
- No guardar ni enviar comandos; no modificar partidas existentes.
- Densidad de píxeles máxima 1.5; una luz con sombras.
- Usar el checkout aislado existente, sin worktree adicional.

## Review Focus
- Sin WebGL: explicación legible en español, sin pantalla vacía.
- Cambio de aspecto de pantalla: casa/personajes/cultivos visibles, sin deformación.
- Scene lifecycle: liberar geometrías, materiales, listeners y render al salir.
- Datos del mundo: el render no muta el objeto recibido.
- Build de producción: incluir ambas entradas, no perder el juego existente.

**Interfaces:** createVisualScene(container: HTMLElement, world: World): {resize(): void; dispose(): void}; models exportan createHouse(), createTree(), createFarmer(color: number), createCropPlot() como THREE.Group. Las posiciones x/y de World se representan en el plano x/z.
