ASTRA - Demo jugable para PC y celular

1. Extrae TODO el ZIP a una carpeta.
2. En Windows, abre JUGAR.cmd con doble clic. Requiere Node.js 24.
3. Se abre el navegador. Pulsa Jugar.

No necesitas npm, Visual Studio, cuentas ni instalar las dependencias del juego.
Deja la ventana abierta. Para terminar: Ctrl+C o cierra la ventana.
Si ya tienes ASTRA abierto con npm run dev, detenlo primero con Ctrl+C.

CELULAR: conecta el telefono al mismo Wi-Fi que la PC. Abre la direccion
que aparece como "Celular" en la ventana. La PC debe seguir encendida.
Si Windows pregunta por el firewall, permite Node.js en tu red privada.

CONTROLES PC
WASD / flechas: caminar. Mouse: apuntar y disparar automaticamente.
Espacio: esquivar (recarga breve). E: interactuar. H: comer.
C: fabricar balas junto a la mesa. M: mapa. Escape: pausa.

CELULAR: joystick izquierdo para mover, derecho para apuntar; botones
para esquivar, interactuar y comer. Horizontal recomendado.

OBJETIVO: cosecha tres parcelas y sobrevive una oleada. Recoge recursos,
fabrica municion junto a la casa y usa las cercas para protegerte.

Demo local de una persona. No guarda progreso al recargar.
El cooperativo del proyecto original sigue siendo una version separada.

En Linux/macOS: node server.mjs y abre http://localhost:5173/
